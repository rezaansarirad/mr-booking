# MR Booking

[English](README.md)

افزونه حرفه‌ای مدیریت نوبت و رزرو برای وردپرس — با تقویم شمسی/میلادی، خدمات، پرسنل، ساعات کاری، تعطیلات، پیامک و ایمیل.

**نسخه:** 1.8.3  
**سازنده:** Reza Ansarirad  
**نیازمندی‌ها:** WordPress 5.8+ · PHP 8.0+

---

## نصب

1. پوشه `mr-booking` را در `wp-content/plugins/` کپی کنید.
2. از پیشخوان وردپرس افزونه **MR Booking** را فعال کنید.
3. جداول دیتابیس و تنظیمات پیش‌فرض به‌صورت خودکار ساخته می‌شوند.
4. **ویزارد راه‌اندازی اولیه** باز می‌شود و این موارد را می‌گیرد:
   - نام کسب‌وکار
   - نوع تقویم (شمسی / میلادی / هر دو)
   - ساعات کاری و روزهای تعطیل
   - پرسنل
   - خدمات فعال
   - قوانین رزرو و رنگ‌های ظاهر

اگر ویزارد را رد کنید، بعداً از منوی **رزروها** → راه‌اندازی اولیه (تا قبل از اتمام) یا تنظیمات قابل پیکربندی است.

نام منوی افزونه در پیشخوان بر اساس زبان سایت وردپرس است: **رزروها** (فارسی) یا **Booking Form** (انگلیسی).

## نمایش فرم رزرو برای بازدیدکنندگان

### شورت‌کد

یک **برگه** در وردپرس بسازید (مثلاً «رزرو نوبت») و این شورت‌کد را در محتوا بگذارید:

```
[mr_booking]
```

ویژگی‌های اختیاری:

```
[mr_booking service="12"]
[mr_booking staff="5"]
[mr_booking theme="default"]
```

### المنتور (Elementor)

اگر Elementor نصب است:

1. صفحه را با Elementor ویرایش کنید.
2. در پنل ویجت‌ها دسته **رزروها** (یا **Booking Form**) را باز کنید (یا «رزرو» را جستجو کنید).
3. ویجت **رزروها** / **Booking Form** را بکشید داخل صفحه.
4. در تب Content: پیش‌انتخاب خدمت/پرسنل.
5. در تب **Style**:
   - رنگ متن، عنوان، پس‌زمینه، کارت و حاشیه
   - فونت کلی، عنوان، برچسب‌ها و مراحل
   - رنگ و فونت دکمه اصلی و دکمه قبلی
   - رنگ کارت خدمات (پس‌زمینه، حاشیه، قیمت، برچسب مدت، حالت انتخاب‌شده)
   - ظاهر فیلدهای ورودی، placeholder و گردی کارت

رنگ‌های فرم را می‌توانید به‌صورت سراسری از **تنظیمات → ظاهر** هم مدیریت کنید.

## رزرو تلفنی (پنل مدیریت)

از **MR Booking → رزرو تلفنی** می‌توانید نوبت را دستی ثبت کنید — مناسب تماس تلفنی یا مراجعه حضوری.

- جستجوی مشتری موجود با نام یا موبایل
- انتخاب خدمت، پرسنل، تاریخ و ساعت
- ثبت یا ویرایش اطلاعات مشتری (نام، موبایل، ایمیل، تاریخ تولد)
- انتخاب وضعیت رزرو (در انتظار یا تأییدشده)

این صفحه از همان موتور اسلات و REST API فرم عمومی استفاده می‌کند.

## نوبت‌ها و مدیریت اسلات

در صفحه **نوبت‌ها**:

- **تأیید** رزرو در انتظار → اعلان تأیید برای مشتری (در صورت فعال بودن)
- **رد** رزرو → اسلات آزاد می‌شود؛ مشتری مطلع می‌شود
- **لغو** رزروهای آیندهٔ تأییدشده → اسلات آزاد می‌شود؛ مشتری مطلع می‌شود
- **حذف** دائمی رزرو → در صورت نیاز اسلات آزاد می‌شود

بعد از تغییر وضعیت، پیام شفاف نمایش داده می‌شود که ایمیل/پیامک ارسال شد، رد شد (بدون ایمیل، غیرفعال و …) یا ناموفق بود.

تعداد رزروهای **در انتظار** روی منوی نوبت‌ها به‌صورت badge نشان داده می‌شود.

لیست‌ها به‌صورت پیش‌فرض بر اساس **زمان ثبت** (جدیدترین اول) مرتب می‌شوند.

## اعلان‌ها

### اعلان به مشتری

ارسال خودکار پیامک و/یا ایمیل در این مراحل:

| رویداد | زمان |
| ------ | ---- |
| **ثبت درخواست** | بلافاصله بعد از ثبت رزرو (رسید در انتظار تأیید) |
| **تأیید رزرو** | بعد از تأیید ادمین |
| **لغو / رد** | هنگام رد، لغو یا حذف رزرو آینده |
| **یادآوری** | قبل از زمان نوبت (طبق تنظیمات) |
| **تولد** | پیامک تبریک تولد (در صورت پیکربندی) |

قالب‌ها را در **اعلان‌ها** شخصی‌سازی کنید. گزینه **«ارسال اعلان تأیید به مشتری»** ارسال تأیید را جدا از رسید اولیه کنترل می‌کند.

اگر قالب خالی باشد، از متن پیش‌فرض استفاده می‌شود. همه ارسال‌ها در جدول `notification_logs` ثبت می‌شوند.

### اعلان به ادمین

با ثبت هر رزرو جدید، ادمین ایمیل (و در صورت فعال بودن پیامک) با جزئیات رزرو و لینک بررسی دریافت می‌کند. گیرندگان را در **تنظیمات → ایمیل** و **تنظیمات → پیامک** (`notify_emails`، `notify_phones`) تنظیم کنید.

### عیب‌یابی ایمیل

اگر مشتری ایمیل تأیید دریافت نکرد:

1. **اعلان‌ها** → «ارسال اعلان تأیید به مشتری» فعال باشد
2. **تنظیمات → ایمیل** → ارسال ایمیل روشن و آدرس From معتبر باشد
3. مشتری ایمیل ثبت کرده باشد (ایمیل اختیاری است مگر **الزام ایمیل** فعال باشد)
4. SMTP/ارسال ایمیل سرور درست کار کند (پلاگین‌هایی مثل WP Mail SMTP کمک می‌کنند)

بعد از تأیید رزرو، پیام پنل دقیقاً توضیح می‌دهد چه اتفاقی افتاده.

## اعلان زنده در پنل

وقتی در هر صفحهٔ MR Booking هستید:

- رزروهای جدید هر ۳۰ ثانیه بررسی می‌شوند
- اعلان toast با نام مشتری و خدمت نمایش داده می‌شود
- صدای اختیاری پخش می‌شود (قابل بی‌صدا کردن)
- لینک مستقیم به لیست نوبت‌ها

## ظاهر و قالب رنگ

**تنظیمات → ظاهر** شامل:

- **قالب‌های آماده** — تم تیره و روشن بر پایه رنگ برند (اصلی `#D4AF37`، ثانویه `#F0D875`، مکمل `#142A38`)
- **برند** — رنگ اصلی، ثانویه، مکمل، متن، برچسب‌ها، ورودی، placeholder
- **دکمه‌ها** — رنگ دکمه ادامه/ثبت و قبلی (عادی و hover)؛ **رنگ اسپینر لودینگ** روی دکمه ادامه/ثبت
- **کارت خدمات** — پس‌زمینه، حاشیه، حالت انتخاب، قیمت، برچسب مدت، تیک
- **تقویم** — روزهای در دسترس، غیرفعال، تعطیل، پر
- **سفارشی** — بعد از اعمال قالب، هر فیلد را جداگانه تنظیم کنید؛ پیش‌نمایش قبل از ذخیره

ویزارد راه‌اندازی می‌تواند رنگ‌های اولیه را در نصب اول تنظیم کند.

## ویجت پیشخوان

از **تنظیمات → پیشخوان** می‌توانید ویجت خلاصه فعالیت را در داشبورد وردپرس فعال کنید و انتخاب کنید چه آمارهایی نمایش داده شود (رزرو امروز، مشتریان، در انتظار تأیید و …).

روی خود ویجت هم از لینک Configure می‌توانید همان موارد را سریع تغییر دهید.

داشبورد MR Booking رزروهای امروز و ثبت‌های اخیر را با ترتیب جدیدترین اول نشان می‌دهد.

## REST API

پایه: `/wp-json/mr-booking/v1/`

| Endpoint | Method | دسترسی | توضیح |
| -------- | ------ | ------ | ----- |
| `/services` | GET | عمومی | لیست خدمات |
| `/staff` | GET | عمومی | لیست پرسنل |
| `/availability/month` | GET | عمومی | موجودی ماه |
| `/availability/slots` | GET | عمومی | اسلات‌های یک روز |
| `/book` | POST | عمومی (nonce) | ثبت رزرو (فرانت) |
| `/settings/public` | GET | عمومی | تنظیمات عمومی فرانت |
| `/admin/customers/search` | GET | ادمین | جستجوی مشتری با نام/موبایل |
| `/admin/book` | POST | ادمین | ثبت رزرو از پنل (رزرو تلفنی) |
